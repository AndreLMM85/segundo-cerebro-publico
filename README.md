# Segundo Cérebro — painel público

Painel responsivo de consulta com projetos, tarefas, contas sem valores e estoque de contingência.

## Privacidade
Este repositório e seus arquivos são públicos. Não inserir saldos, valores, renda, dados de saúde, identificadores, nomes completos de clientes, contatos, horários familiares, rotas, endereços, credenciais ou links privados. Ocultar na interface não protege o conteúdo dos arquivos. A diretiva noindex é apenas uma solicitação a buscadores, não controle de acesso.

Histórico novo: nenhum commit do repositório privado foi importado. Informações não confirmadas ficam explicitamente pendentes. Não inferir atraso a partir de pagamento desconhecido.

## Arquivos
- index.html: interface e renderização com textContent.
- data/dashboard.json: apenas dados autorizados para publicação.
- .nojekyll: desativa processamento Jekyll.

## Publicação
No GitHub: Settings > Pages > Deploy from a branch > main > / (root) > Save. Publicação deve ser confirmada na interface; envio de arquivos não significa site publicado.

## Atualizações
Comando de trabalho: atualizar quadro geral. Ler o estado atual, preparar alterações, obter confirmação e enviar somente o conteúdo aprovado. Sem sincronização bancária ou de agenda em tempo real.
